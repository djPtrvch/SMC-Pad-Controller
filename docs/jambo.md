# JAMboPAD и JAMbo

Как пэды работают с JAMbo (нативная Swift-версия, CoreMIDI; в Safari Web MIDI нет).

## Главное для JAMbo
Раскладка пэдов свободная: что шлёт каждый пэд, ручка и кнопка, пользователь задаёт в конфигураторе JAMboPAD. JAMbo **не должна** рассчитывать на конкретные номера нот и CC — назначение делается обычным MIDI LEARN (и, по желанию, пресетом маппинга). Банки пэдов (до 4 на профиль) переключаются **внутри пэда** кнопками с действием PAD BANK и MIDI при этом не шлют; JAMbo видит только сообщения текущего банка. Поэтому у разных банков должны быть разные сообщения (например, свой MIDI-канал на банк) — тогда один пэд в банке SEQ и в банке MUTE назначается на разные цели.

Что JAMbo нужно уметь:
1. Обычный MIDI-маппинг входящих нот и CC (уже есть) и обратная связь на тот же номер и канал — пэд светится цветом «от приложения» с яркостью = значению (0 — гаснет).
2. Отправка гаммы, тоники и октавы (SET_SCALE, ниже).
3. Приём тоники (65) и гаммы (67), выбранных на пэде.
4. По желанию: режим MIDI OUT пэда (SET_MIDI_OUT) в настройках MIDI.

## Подключение
Два SMC-PAD по USB (хаб с питанием) или по Bluetooth MIDI. По USB пэд называется «SMC-PAD», по Bluetooth — «JAMboPAD L» / «JAMboPAD R». Сторона (LEFT / RIGHT) хранится в пэде. Гамма по Bluetooth MIDI пока не доходит (библиотека Bluetooth MIDI в ядре open-smc-pad не передаёт SysEx) — по USB работает.

## Раскладка по умолчанию (пример, меняется в конфигураторе)
Каналы MIDI — как в меню JAMbo (1–16).

| Что | Сообщения | Подходящая цель в JAMbo |
|---|---|---|
| 16 ручек (левый блок — колонки 1–2, правый — 3–4) | CC 0–15, канал 1, ABSOLUTE, CC = ряд·4 + колонка | KNOB 1.1–4.4 — как пресет Twister |
| Левый блок, банк 1 | ноты 36–51 (от левого нижнего пэда), канал 2 | STEP 1–16 |
| Левый блок, банк 2 (KEYS) | ноты гаммы, канал 4 | MIDI → NOTES (канал 4 или ALL) |
| Левый блок, банк 3 | ноты 36–51, канал 5 | MUTE 1–16 |
| Левый блок, банк 4 | ноты 36–51, канал 6 | T1–T16 |
| Левый блок, 4 кнопки | открывают банки 1–4 (MIDI не шлют) | — |
| Левый блок, 6 кнопок | ноты 4–9, канал 2 | любые кнопки JAMbo |
| Правый блок, пэды | ноты 36–51, канал 3 | любые кнопки JAMbo |
| Правый блок, кнопки | ноты 0–9, канал 3 | любые кнопки JAMbo |

## Гамма на пэдах (банк KEYS)
Пэды показывают гамму, корень подсвечен (CHROMATIC — все ноты, гамма горит, как в MPC; IN KEY — только ноты гаммы). Ноты считаются как в JAMbo: нижняя нота = 12·(октава + 1) + корень, октавы 0–7, гаммы — список Scales.swift (Major … Chromatic).

Чтобы гамма менялась вместе с JAMbo, JAMbo шлёт пэдам SysEx (FOLLOW JAMbo в профиле включён по умолчанию):

```
F0 7D 4A 50 0C <root 0–11> <mask биты 0–6> <mask биты 7–11> <octave 0–7> F7
```
mask — бит k: нота на k полутонов выше корня входит в гамму (Major 0xAB5 → 35 15). Слать при смене SCALE, ROOT и октавы клавиатуры и при подключении выхода, на все выходы (ответа нет; другие устройства SysEx с ID 7D игнорируют). Отправку в JAMbo пользователь делает сам.

## Корневая нота с пэда
Кнопка с действием KEY NOTE (назначается в конфигураторе, по умолчанию не стоит): держишь её — три нижних ряда пэдов становятся C … B, текущая горит жёлтым; тап выбирает. Пэд сразу играет KEYS от новой ноты и шлёт JAMbo:

```
F0 7D 4A 50 65 <root 0–11> F7
```
JAMbo, приняв, меняет ROOT (и шлёт SET_SCALE в ответ — пэды остаются согласованы).

## Гамма с пэда
Кнопка с действием SCALE: держишь её — 11 нижних пэдов (от левого нижнего, как блок стоит) — гаммы в порядке JAMbo (Major, Minor, Dorian, Phrygian, Lydian, Mixolydian, Locrian, Harm Minor, Pent Major, Pent Minor, Chromatic); текущая горит жёлтым, тап выбирает. Пэд сразу играет KEYS в новой гамме и шлёт:

```
F0 7D 4A 50 67 <номер гаммы 0–10> <mask биты 0–6> <mask биты 7–11> F7
```
JAMbo, приняв, меняет SCALE (номер — индекс в Scales.all). Тонику и гамму можно поставить на две разные кнопки (KEY NOTE и SCALE).

## MIDI OUT из JAMbo
Режим разъёма можно менять из JAMbo (сохраняется в пэде):

```
F0 7D 4A 50 0D <thru: 0 OFF, 1 CLOCK, 2 ALL> <pad messages 0/1> F7
```
Ответ: F0 7D 4A 50 4D <status 0 = OK> F7.

Тип A/B (какой контакт TRS — кончик или кольцо — ток, какой — данные) задан проводкой внутри SMC-PAD; прошивка его не меняет. Нужен переходник того же типа, что у пэда, или переключаемый (A/B).

## MIDI-клок на 3,5 мм
JAMbo: SYNC → MIDI CLOCK SYNC ON, CLOCK SOURCE SEND, CLOCK OUTPUT ALL OUTPUTS. Пэд (DEVICE → MIDI OUT → FROM THE APP: CLOCK — по умолчанию) передаёт клок, START, CONTINUE и STOP на свой разъём MIDI OUT. Два пэда — два выхода. ALL — всё, что JAMbo шлёт пэду (ноты дорожек с MIDI OUT и т. п.). Разъём работает программно (ядро open-smc-pad UART для него не настраивает) — проверить на устройстве.
